## بدهی فنی شناخته‌شده

| مورد | وضعیت | راه‌حل |
| --- | --- | --- |
| سبد خرید فقط محلی | `localStorage` | همگام‌سازی سرور پس از ورود |
| توکن در `localStorage` | ریسک XSS | کوکی `httpOnly` + CSRF |
| محدودیت نرخ وابسته به cache | یک سرور | Redis |
| به‌روزرسانی پررندر بعد از تغییر محتوا | دستی: `seo:refresh` + `seo:prerender` | هک webhook پنل به اسکریپت build |
| بدون صف | `QUEUE_CONNECTION=database` بی‌استفاده | صف برای پیامک و ایمیل |
