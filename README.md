# نودهی — فروشگاه اینترنتی لوازم خانگی

فروشگاه آنلاین لوازم خانگی با API **Laravel 12** و رابط کاربری **React 18 + Vite**.
دیتابیس پیش‌فرض SQLite است تا پروژه بدون سرویس بیرونی بالا بیاید و در تولید با
تغییر چند متغیر محیطی به MySQL/PostgreSQL منتقل شود.

## پیش‌نیازها

- PHP **8.2 یا بالاتر** با افزونه‌های `pdo_sqlite`، `mbstring`، `openssl`، `curl`
- Composer
- Node.js **18 یا بالاتر** و npm

> روی ویندوز با XAMPP می‌توانید از `C:\xampp\php\php.exe` استفاده کنید.
> اگر Composer نصب نیست، فایل `tools/composer.phar` در مخزن موجود است.

## نصب و اجرا

```bash
# ۱) بک‌اند
cd backend
cp .env.example .env
php ../tools/composer.phar install
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed

# ۲) فرانت‌اند
cd ..
npm --prefix frontend install

# ۳) اجرای هم‌زمان API و وب
npm run dev
```

- API: <http://127.0.0.1:8000>
- فروشگاه: <http://127.0.0.1:5173>
- پنل مدیریت: <http://127.0.0.1:5173/admin> — با شماره‌ای وارد شوید که
  `role=admin` دارد؛ در دادهٔ نمونه `09120000000` مدیر است.
  برای مدیر کردن یک کاربر: `php backend/artisan tinker` و سپس
  `App\Models\User::where('phone','0912...')->update(['role'=>'admin']);`

در ویندوز، `touch` را با ساخت دستی فایل `backend/database/database.sqlite` جایگزین
کنید. اسکریپت `composer run setup` در پوشهٔ `backend` هم همین گام‌ها را انجام می‌دهد.

### اجرای جداگانه

```bash
php backend/artisan serve --host=127.0.0.1 --port=8000
npm --prefix frontend run dev
```

### بررسی‌ها

```bash
npm --prefix frontend run typecheck
npm run test:unit                     # تست‌های سئو (vitest از ریشه)
npm run seo:refresh                   # تازه‌سازی فهرست کاتالوگ از API (نیازمند API)
npm run seo:prerender                 # build کامل + پررندر صفحات ایستا + sitemap
php backend/artisan test
```

## تنظیمات محیطی

تنظیمات بک‌اند در `backend/.env` است. مهم‌ترین کلیدها:

| متغیر | توضیح |
| --- | --- |
| `APP_DEBUG` | در تولید حتماً `false` |
| `APP_URL` | آدرس API، مثلاً `https://nodehi.ir` |
| `FRONTEND_URL` | تنها مبدأ مجاز CORS، مثلاً `https://nodehi.ir` |
| `DB_CONNECTION` | `sqlite` یا `mysql` / `pgsql` |
| `AUTH_OTP_DEV_MODE` | فقط توسعه؛ کد را در پاسخ API برمی‌گرداند |
| `AUTH_SESSION_DAYS` | طول عمر نشست ورود |
| `KAVENEGAR_API_KEY` | برای ارسال واقعی کد ورود |
| `KAVENEGAR_OTP_TEMPLATE` | نام قالب کد ورود در کاوه‌نگار |

فرانت‌اند در توسعه از پروکسی Vite به `127.0.0.1:8000` استفاده می‌کند. در تولید
`VITE_API_URL` را روی آدرس API تنظیم کنید (`frontend/.env.example`).

## تصمیم‌های مهم

**قیمت فقط روی سرور محاسبه می‌شود.** کلاینت فقط نامک محصول و تعداد را می‌فرستد؛
قیمت، تخفیف، هزینه ارسال و موجودی از دیتابیس خوانده می‌شوند.

**ورود بدون رمز عبور.** کد یک‌بارمصرف با SHA-256 و نمک شماره ذخیره می‌شود، با هر
درخواست تازه کد قبلی باطل می‌شود و سقف درخواست برای هر شماره و هر IP اعمال می‌گردد.
توکن نشست فقط به شکل هش در دیتابیس می‌ماند.

**کلید جلوگیری از سفارش تکراری به صاحب سفارش محدود است.** استفادهٔ دوبارهٔ همان کلید
توسط شمارهٔ دیگر، به‌جای افشای سفارش قبلی، پاسخ ۴۰۹ می‌گیرد.

**موجودی سفارش آنلاین قبل از پرداخت کم نمی‌شود.** سفارش پرداخت در محل در وضعیت
`processing` ثبت و موجودی کم می‌شود؛ سفارش آنلاین/اقساطی تا تأیید تراکنش `pending`
می‌ماند.

**فایل‌های seed کاتالوگ در `backend/database/seeders/data/` هستند.** این پوشه نباید
با هیچ الگوی عمومی مانند `data/` در `.gitignore` نادیده گرفته شود.
